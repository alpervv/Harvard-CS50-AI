# Harvard-CS50-AI
An AI to identify which traffic sign appears in a photograph.

I used a convolutional neural network. My network tests 32 different convolutions and uses 2*2 pooling. I didn’t modify these parameters. My output layer consisted of NUM_CATEGORIES neurons with activation function “softmax”. For optimizer I tired “SGD” and “adams” but decided that “adams” was a better one and sticked with it. For loss function I used “categorial_crosentropy”.

I tried using one hidden layer with 128 neurons and activation function “relu”. For this layers I added a dropout of %50. With this network I was almost always stuck at %5 accuracy. I tried getting rid of the dropout which got the model to work. However testing accuracy was lower than accuracy of final training epoch. I believe this is due to the fact that my network “memorizes” the data so I tried finding a model that worked with dropout. I decided to change the activation function. In my first network, the one with %50 dropout, I changed the activation function of hidden layer to “selu”. This model generally got stuck at %4 accuracy; however, someties it achieved a breakthrough and got up to %94 accuracy in testing. I then added another hidden layer with 64 neurons and an activation function “relu” without dropout. This model mostly got stuck at %6 accuracy. I decided that %50 dropout was way too much so I decreased it to %25. Finally this compiled model produced about %90-95 accuracy each time I trained it. Sometimes it was too lucky and accuracy started mounting up in first or second training epoch. Sometimes it got unluck but still was able to recover ar 5th or 6th epoch. Lastly I tried modifying number of epochs. After trying several cases I noticed accuracy barely improved after 12th epoch so I fixed the number of epochs to 12.
